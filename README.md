# Flashpoint

A browser-based multimedia creation tool with Flash's approachability and the modern web as its target.

Draw. Animate. Script. Publish to a single HTML file that runs anywhere.

**No install. No subscription. No prior experience required.**

## The Problem

The Flash era (1997–2010) produced more creative work per capita than anything before or since. Individuals and teenagers made games, animations, and interactive art with no budget and no professional training. Steve Jobs killed Flash in 2010 to protect iOS. The ecosystem never recovered because no tool matched Flash's approachability.

Godot is excellent but requires understanding its engine architecture before anything moves. Unity is more powerful and further from accessible. Nothing has Flash's ramp from "I opened the tool" to "something I made is on screen."

Flashpoint is the attempt to fix that.

## Status

Early design and development. See [DESIGN.md](docs/DESIGN.md) for full architecture and roadmap.

## Core Ideas

- **Timeline + Stage** — the Flash mental model, proven to work
- **Built-in drawing** — no external assets required to start
- **Flare scripting** — readable by non-programmers, attached to frames and objects
- **Single-file publish** — one HTML file, runs in any browser, no dependencies
- **Free and open-source** — cultural project, not a product
